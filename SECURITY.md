# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
**[Report a vulnerability](https://github.com/Hdisra/ToiletFinder/security/advisories/new)**
(or open the repository's **Security** tab and choose **Report a vulnerability**).

Please include:

- what the problem is and where it is (the route, screen or file),
- the steps to reproduce it,
- what an attacker could do with it.

I will answer as soon as I can and keep you informed until it is fixed. Please give me a
reasonable time to fix it before you share the details publicly.

## Scope

This repository contains the backend (`backend/`), the admin web app (`frontend/`) and the
mobile app (`mobile/`). Reports about the code, its dependencies or its configuration are welcome.

## Secrets

This repository must never contain real secrets. If you find a password, key or token in the
code or in the history, please report it the same way, privately.
